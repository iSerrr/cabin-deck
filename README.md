# Cab Deck

Планшетна панель кнопок для American Truck Simulator і Euro Truck Simulator 2 (один движок SCS, налаштування однакові). Python-сервер на ПК роздає сторінку з кнопками в домашній Wi-Fi мережі й натискає кнопки віртуального джойстика vJoy. Гра бачить vJoy як звичайний контролер.

```
Планшет (браузер) ──WebSocket──► server.py ──pyvjoy──► vJoy ──► ATS / ETS2
```

## Одноразове налаштування Windows-ПК

1. **Git for Windows** і **Python 3.10+**. В інсталяторі Python постав галочку «Add python.exe to PATH».
2. **vJoy**: реліз 2.1.9.1 з https://github.com/jshafer817/vJoy/releases. Якщо Windows 11 не приймає драйвер, бери https://github.com/BrunnerInnovation/vJoy/releases.
3. **Configure vJoy**: пристрій 1, Enable vJoy, Number of Buttons = 32, Apply.
4. **Клонувати проєкт**:
   ```
   git clone https://github.com/iSerrr/cabin-deck.git C:\cab-deck
   ```
5. **Брандмауер**: PowerShell від імені адміністратора:
   ```
   New-NetFirewallRule -DisplayName "Cab Deck 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Profile Private -Action Allow
   ```
   Домашня Wi-Fi мережа в Windows має бути «Приватною» (Параметри → Мережа та Інтернет → Wi-Fi → властивості мережі).
6. **Планшет**: вимкни автоблокування екрана. На iPad відкрий панель у Safari → «Поділитися» → «На початковий екран», щоб вона запускалась на весь екран.

## Запуск

Подвійний клік по `C:\cab-deck\run.bat`. Він підтягує свіжий код з GitHub, оновлює залежності й запускає сервер. Сервер друкує адресу панелі:

```
Open the panel on the tablet:
  http://192.168.x.x:8000
```

Відкрий її на планшеті. Зелена крапка вгорі означає, що з'єднання є.

## Повний екран на планшеті

**Швидкий спосіб.** Перший дотик до панелі сам вмикає повноекранний режим, без адресного рядка й вкладок. Свайп від верхнього краю тимчасово показує системні панелі. Щоб повернути браузер, торкнись ледь видимої кнопки в правому нижньому куті: після цього панель більше не вмикатиме повний екран сама, аж до перезавантаження сторінки.

**Як застосунок з робочого столу (Android, Chrome).** Без HTTPS Chrome не дає встановити сторінку як повноекранний застосунок. Обхід — дозволити саме цю адресу:
1. На планшеті в Chrome відкрий `chrome://flags`.
2. Знайди «Insecure origins treated as secure» і впиши адресу панелі, наприклад `http://192.168.2.112:8000`. Увімкни прапорець (Enabled) і натисни Relaunch.
3. Відкрий панель, меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
4. Запускай Cab Deck з іконки: він відкриється на весь екран в альбомній орієнтації, а екран не гаснутиме під час гри (Wake Lock працює лише в цьому режимі).

Прапорець послаблює захист лише для однієї вказаної адреси. Щоб вона не змінювалась, закріпи за ПК постійну IP-адресу в налаштуваннях роутера (DHCP reservation).

## Призначення кнопок у грі

1. Запусти сервер і відкрий панель на планшеті.
2. У грі: Параметри → Керування. Вибери дію, натисни на призначення й торкнись потрібної кнопки на планшеті.
3. Гра рахує кнопки джойстика з нуля, а vJoy з одиниці. Тому `cab_deck_btn_001` гра показує як Button 0, а `cab_deck_btn_007` — як Button 6.

## Стан гри на панелі

Кнопки підсвічуються за реальним станом вантажівки: світло, поворотники, аварійка, двигун, гальмо, причіп. Для цього потрібен плагін телеметрії:

1. Скачай `release_v_1_12_1.zip` з https://github.com/RenCloud/scs-sdk-plugin/releases/tag/V.1.12.1.
2. Поклади 64-бітний `scs-telemetry.dll` у `<папка гри>\bin\win_x64\plugins\`. Папку `plugins` створи, якщо її немає.
3. При запуску гри підтверди вікно про розширені функції SDK.

Без плагіна панель працює як раніше, тільки без підсвітки. У верхньому рядку видно стан: «немає телеметрії», «не запущена», «пауза» або «в кабіні».

### Перемикачі: світло, двірники, ретардер

Торкнись потрібного положення, і панель сама натисне потрібну дію гри потрібну кількість разів.

- **LIGHTS** (OFF / PARK / LOW): гра вміє лише «наступне положення», тому панель натискає «Light modes» по колу. Положення береться точно з телеметрії.
- **WIPERS** (OFF / 1 / 2 / 3): «Wipers» вперед і «Wipers back» назад. Гра не повідомляє режим, тож панель рахує його сама. Якщо двірники вимкнули з клавіатури, перемикач сам повернеться на OFF приблизно за секунду.
- **RETARDER** (OFF / 1…5): «Retarder increase» і «Retarder decrease». Положення й кількість ступенів беруться з телеметрії; зайві ступені ховаються.

### Екран SETUP

SETUP показує всі кнопки vJoy з конфігу: номер vJoy, номер у грі й назву дії в ATS. Один дотик до плитки дає рівно одне натискання цієї кнопки. Це потрібно для перемикачів (світло, двірники, ретардер): у звичайному режимі вони самі вирішують, що й скільки разів натиснути. Там же регулятор яскравості панелі (BACKLIGHT).

Як відкрити: кнопка-шестерня на табличці статусу вгорі або свайп вліво по табличці. Закрити: BACK, шестерня або свайп вправо.

Там же перемикач CONSOLE — оздоблення панелі: GREEN (темно-зелена консоль у колір кабіни, за замовчуванням), WALNUT (горіх) або GRAPHITE (оригінальний v6). Вибір запам'ятовується на планшеті.

Як призначити кнопку:
1. У грі відкрий Параметри → Керування і натисни на призначення потрібної дії.
2. На планшеті відкрий SETUP і торкнись плитки з цією дією.

Сервер зупиняти не треба. SETUP натискає лише кнопки, описані в `config.json`.

## Конфіг

Зовнішній вигляд панелі задає `static/index.html` (дизайн Cab Deck v6, один екран 1194×834, масштабується під будь-який планшет). `config.json` описує поведінку: які контроли є, які кнопки vJoy вони натискають і який стан гри показують. Нова кнопка — це рядок у `controls` і плитка в `index.html`; на екрані SETUP вона з'являється автоматично.

```json
{"id": "cab_deck_btn_024", "label": "INTERIOR", "type": "tap", "action": "Interior light"}
```

- `id`: `cab_deck_btn_NNN`, де `NNN` — номер кнопки vJoy.
- `type`: `tap` (коротке натискання на `tap_ms` мілісекунд) або `hold` (затиснута, поки палець на кнопці, але не довше `hold_timeout_s` секунд).
- `indicator` (необов'язково): який стан гри показує кнопка: `engine`, `lights`, `high_beam`, `blinker_left`, `blinker_right`, `hazards`, `park_brake`, `wipers`, `trailer`.
- `action` (необов'язково): назва дії в меню ATS, показується на вкладці SETUP. Для перемикачів — `forward_action` і `back_action`.
- Перемикач: `"type": "switch"`, `positions` (назви положень), `forward` і `back` (ID кнопок vJoy для «вперед» і «назад»). `"cyclic": true` — перемикач по колу лише з `forward` (світло). `position_source` (`retarder` або `lights`) — положення береться точно з гри.
- Прилад: `"type": "gauge"`, `indicator` (зараз лише `air_pressure`), `min` і `max` для шкали. Нічого не натискає.
- Індикатори етапу 3: `retarder`, `engine_brake`, `diff_lock`, `lift_axle`, `trailer_lift_axle`, `beacon`, `aux_front`, `aux_roof`, `air_pressure`.

Якщо конфіг зламаний, сервер не стартує й пише, що саме не так.

## Розробка на Mac

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py --dry-run
```

У режимі `--dry-run` vJoy не потрібен: натискання лише пишуться в лог. Порт можна змінити через `--port 8077`.

Цикл роботи: код і перевірка на Mac → `git push` → `run.bat` на Windows.

## Діагностика

Лог пише у `logs/cab_deck.log`, а також доступний по мережі:

- `http://<ip-пк>:8000/api/health` — стан: режим вводу, кількість кнопок vJoy, затиснуті кнопки, підключені панелі, git-коміт, остання помилка.
- `http://<ip-пк>:8000/api/logs?lines=200` — останні рядки логу.

Помилки JavaScript з панелі на планшеті теж потрапляють у цей лог з позначкою `Panel error`.

## Якщо щось не працює

| Симптом | Що робити |
| --- | --- |
| `Cannot open vJoy device 1` | Перевір Enable vJoy у Configure vJoy. Якщо не допомогло, скопіюй `C:\Program Files\vJoy\x64\vJoyInterface.dll` у `.venv\Lib\site-packages\pyvjoy\utils\x64\` |
| `vJoy device has only 8 buttons` | Збільш Number of Buttons у Configure vJoy |
| Планшет не відкриває сторінку | Брандмауер (крок 5), мережа «Приватна», планшет у тій самій Wi-Fi |
| `address already in use` | Сервер уже запущений в іншому вікні або порт зайнятий: `run.bat --port 8001` |
| Червона крапка на панелі | Сервер зупинився або зник Wi-Fi. Панель перепідключиться сама |
